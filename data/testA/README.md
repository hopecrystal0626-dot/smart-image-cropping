# 当前文件夹图片对说明

本文件记录当前文件夹内原图与扩展图的对应关系，以及扩展后原图在画布中的位置参数。原图命名示例A01.jpg，取景图命名示例A01_framing.jpg

## 字段说明

- **orig_img_name**: 原始大图的名称。
- **cx_norm**: 取景中心点在画布上的 X 轴归一化坐标（0.0 到 1.0 之间）。计算逻辑: 取景中心 X 坐标 / 画布总宽度。
- **cy_norm**: 取景中心点在画布上的 Y 轴归一化坐标（0.0 到 1.0 之间）。计算逻辑: 取景中心 Y 坐标 / 画布总高度。
- **yw**: 取景宽度在画布上的归一化占比（YOLO width）。计算逻辑: 取景宽度 / 画布总宽度。
- **yh**: 取景高度在画布上的归一化占比（YOLO height）。计算逻辑: 取景高度 / 画布总高度。
